# Stack artwork

The profile uses self-contained SVG icons with logos from [Devicon](https://github.com/devicons/devicon/tree/7330accdbc47e2dc0c19789a48533c4a3c50fe58), revision `7330accdbc47e2dc0c19789a48533c4a3c50fe58`. The original logo paths are retained; labels, spacing and theme backgrounds are added for this profile.

Devicon is distributed under the [MIT license](LICENSE-devicon.txt). Product names and logos belong to their respective owners; their use does not imply endorsement.

Each icon has a light and dark variant selected by the profile README using `<picture>`. The light SVG is the fallback. Icons wrap onto a new line on narrow screens. No external image service is needed to render the stack.
